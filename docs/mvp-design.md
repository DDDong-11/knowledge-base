# 个人开发知识库（代码片段管理器）MVP 设计方案

> 版本：v1.0（MVP）
> 定位：本人（Java 业务后端开发）在业余时间打造一款本地离线、轻量、可插件扩展的开发者知识库，用于收纳代码片段、命令行、踩坑笔记与技术模板。核心目的是：自己日常真的能用 + 落地一套「跨进程 + 扩展系统」的架构作品，作为技术沉淀与博客素材。

---

## 一、项目定位

一款**本地离线、轻量、可插件扩展的开发者知识库**，承载碎片化开发经验。

核心特点：
- **快速存入**：手动录入 + 剪贴板捕获，随手保存
- **秒级检索**：全文搜索，只记得内容也能捞出
- **可扩展**：能力由插件提供，主程序内核保持精简
- **全程本地**：数据不联网、不上云

技术亮点（用于写博客 & 简历）：
**Electron 作为视图层与插件宿主，Java 作为数据内核与检索内核**，实现前后端跨进程架构 + 插件沙箱扩展系统。

---

## 二、MVP 功能清单

### 1. 核心知识库功能（用户可直接使用）

| 功能 | 说明 |
| --- | --- |
| 片段管理 | 新增 / 编辑 / 删除文本或代码片段，支持标题、标签、正文、语法高亮 |
| 全文搜索 | 按标题 / 标签 / **正文任意内容**检索，按匹配度展示；MVP 用数据库模糊匹配实现，后续可无缝升级 Lucene |
| 快速唤起 | 全局快捷键一键打开 / 隐藏窗口 |
| 剪贴板捕获 | 复制内容后弹窗提示是否保存为新片段，避免随手丢失 |

### 2. 极简插件系统（项目技术核心，对标 Electron 扩展架构）

- 主程序**不内置格式化、导出等附加能力**，全部由插件提供
- 插件具备标准化生命周期：`activate`（启用）/ `dispose`（销毁）
- 插件运行隔离：独立进程运行，基础权限管控
- 内置 2 个极简插件保证架构跑通：
  - JSON 格式化插件
  - 片段 Markdown 导出插件

## 三、整体技术架构（双进程混合架构）

```
┌──────────────────────────────┐
│         Electron 层           │
│  ┌─────────────┐ ┌─────────┐ │
│  │ 窗口/UI/快捷键 │ │ 插件宿主  │ │
│  │ 剪贴板监听   │ │ 插件生命周期│ │
│  └──────┬──────┘ └────┬────┘ │
│         │ 本地HTTP通信 │        │
└─────────┼──────────────┴──────┘
          │
┌─────────▼──────────────┐
│       Java 层           │
│  片段CRUD / 标签管理     │
│  全文检索               │
│  本地数据库持久化(H2)     │
└────────────────────────┘
```

### 1. 各层职责

**Electron 层（视图层 + 插件宿主层）**
- 职责：窗口管理、全局快捷键、剪贴板监听、页面 UI、搜索与展示、插件系统宿主与生命周期管理、IPC 通信客户端
- **不负责**：数据存储、检索、复杂业务逻辑

**Java 层（数据内核层）**
- 职责：片段 CRUD、标签管理、全文检索、本地数据库持久化
- 对外提供统一接口供 Electron 调用

### 2. 进程通信方案（MVP 最简）

- 通信方式：**HTTP 本地接口**（Java 启动内嵌 Tomcat，仅本机监听；Electron 通过 axios 调用本地接口完成搜索、保存、查询）
- 选择理由：业余项目最简、最稳，不用折腾 gRPC / stdio
- 后续可升级为 stdio 二进制通信，MVP 阶段不做

## 四、技术栈

| 端 | 技术选型 | 说明 |
| --- | --- | --- |
| Electron | TypeScript + Electron（主进程/渲染进程/preload） | UI 从简，够用即可 |
| Java | Spring Boot（最小体项目） | 后台内核 |
| 数据库 | H2 本地嵌入式数据库 | 开箱即用，无需安装 MySQL |

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Long | 主键 |

| content | TEXT | 正文 / 代码内容 |

| updateTime | Datetime | 更新时间 |

## 六、MVP 运行流程

1. 启动 Java 后台服务（静默运行）
2. Electron 客户端启动，连接本地 Java 服务
3. 用户可：
   - 手动新增笔记 / 代码片段
   - 复制内容自动提示保存
   - 输入关键词**全文检索**所有历史片段
   - 使用插件格式化、导出内容
4. 所有数据保存在本地目录，不上云、不联网

---

## 七、MVP 明确不做（防烂尾边界）

- ❌ 云同步 / 账号登录
- ❌ 双向链接、思维导图、复杂排版
- ❌ 多端同步
- ❌ AI 功能（后续可作为插件扩展）
- ❌ 精美 UI
